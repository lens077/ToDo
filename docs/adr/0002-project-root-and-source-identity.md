# 项目目录聚合发现，原文件继续拥有任务

项目选择从单个 `TODO.md` 扩展为目录边界，递归发现大小写不敏感的 `TODO.md`、`TODO` 和 `TODO.txt`。选择汇总视图而不是合并写入一个中心文件，是为了保留已有文件组织、文件内稳定 ID、说明和 Git 物证；跨来源身份采用「来源相对路径 + 文件内 ID」，每次写入只定位一个来源，多来源写入不伪装成事务。

发现与接管分开：普通文本和未接管清单只读展示，用户检查差异并确认后才添加格式声明和缺失 ID。项目边界不要求等同于 Git 根；不跟随来源符号链接，HTTP 只操作启动时绑定的根，不提供任意磁盘目录切换接口。单文件 CLI 的既有路径语义保留，`todo serve` 则绑定当前目录。具体范围与验证见 `../project-root-spec.md`。
