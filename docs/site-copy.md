## 2 · 怎么用

标题：

> 三十秒，把清单对回代码。

> **打开项目目录。** Virgo 找出目录里所有的 `TODO.md`（以及声明了 `todo-spec` 的
> Markdown），按来源分开列出，不需要登录，也不需要网络。
>
> **看对账结果。** 每一项旁边是 Git 里能找到的物证：哪些改动、哪个区间。没有物证的、
> 物证和状态对不上的，标出来。
>
> **在原地写结局。** 完成、部分完成（`◐`）、失败（`⚠`）都在那一行写完，附一句说明。
> 写回去的只有 Virgo 认识的那几个字节，文件里其他内容逐字节不动。
>
> **agent 读同一份文件。** `todo hooks install --agent claude|codex|deepseek-harness`，
> 它在会话开始时读到的就是你刚对过账的清单。

小字：`真实界面 · 演示数据`（截图就位后）

## 3 · 边界（如实告知）

标题：

> 它只报告，不替你改。

> **文件是事实，界面是视图。** SQLite 只是派生的索引，随时可以从 Markdown 重建。删掉
> Virgo，你的 `TODO.md` 还是一份普通的 Markdown，任何编辑器都能开。
>
> **物证证明改动存在，不证明任务完成。** 对账结果是「这一项在 Git 里有 / 没有对应的
> 改动」，勾不勾永远是人的决定。
>
> **每次写入之前先建还原点。** `.todo/history/` 默认保留 200 个。整文件改写（扫描导入、
> 版本恢复）必须先看左右 diff 再确认；预览期间文件被别人改了，写入会被拒绝，提示
> 「文件已在外部更新，请重试」。
>
> **不需要网络，不需要登录。** 本地模式打开目录就能用。语义对账默认关闭；打开它需要
> 你自己的 LLM key，请求从你的机器直接发到你选的服务商，不经过我们的服务器。
>
> **个人随记不进仓库。** 速记窗口（`⌘⇧Space`）记下的东西存在 `~/.todo/inbox.md`，
> 不受项目还原点保护，也不会被提交。

## 4 · 能放什么

标题：

> 四个视图，一份文件。

| 视图 | 一句话 |
| --- | --- |
| 目标 | 推进中、待办、已完成在同一个工作区；推进中默认展开 1 项，最多 5 项 |
| 象限 | 按 `!1`–`!4` 拖进四格，写回的只是那一行的 `!` 标记；没定级的留在托盘 |
| 随记 | 个人收件箱与分拣；`⌘⇧Space` 随时记一条，`⌘⏎` 保存 |
| 扫描与历史 | 全仓扫描未跟踪的工作，导入前看 diff；查看与恢复还原点 |

格式一行：

> `- [ ] 任务 !2 ◐ ↳ 说明 🔗 a1b2c3..d4e5f6 <!-- id -->` —— 优先级、部分完成、说明、
> 物证、稳定 ID 都是文件里的普通字符。CLI `todo` 和桌面端读写同一套。
