# 桌面端 MVP 规格

本文定义 Tauri 桌面端的首版范围与验收标准。项目选择以目录为根，递归汇总各 Task Source 的 Project Task，原文件继续是事实源；桌面端只提供视图和安全编辑入口。目录发现、来源身份、只读预览与显式接管的当前约定见 `project-root-spec.md`，其规则优先于本文旧有单文件措辞。

## 1. 信息架构

主窗口包含四个一级视图：

1. **目标**：把推进中、待办、已完成放在一个工作区，按 `TODO.md` 的列展示 Project Task，支持新增、完成、取消完成、跨列拖动，以及在卡片内记录部分完成与失败。逾期 / 今天 / 7 天内作为筛选叠加在待办之上，不创建独立任务副本。
2. **随记**：展示个人 Capture 收件箱，并支持分拣为当前项目的 Project Task。
3. **AI**：展示外部 agent 宿主发布的会话状态，位于「随记」之后；见 §5.1。
4. **扫描与历史**：扫描全仓未跟踪工作、预览导入 diff，以及查看和恢复还原点。

左侧导航显示当前项目、各一级视图和同步状态。顶部命令栏提供项目切换、快速新增和对账入口。项目未打开时显示项目选择空状态，不自动接管或改写文件；上次打开的项目记录在 `~/.todo/desktop.json`，下次启动自动载入，失败时静默回到空状态。

## 2. 视觉方向

产品负责人已确认以「市政简报」`civic-bureau-prospectus-late-modern` 替换原「工程笔记与编辑台」方向。当前视觉权威为 `apps/desktop/DESIGN.md`；产品约束见 `PRODUCT.md`。本节不再维护一套独立配色或组件配方。

- 遵循 macOS 原生惯例，保留键盘优先、清晰状态与紧凑操作密度。
- 外观跟随系统，同时提供浅色与深色；界面采用系统字体，ID、日期、Git 物证和快捷键采用系统等宽字体。
- 替换范围覆盖四个一级视图、对话框、菜单和速记窗口；产品事实、写入策略和交互语义不因此改变。
- 丝带仅在光标交互时响应，静止时不持续动画；减少动态效果偏好下保持静态。禁止无意义的持续浮动和全局弹跳。

历史说明：原约定禁止系统字体、紫色主视觉与默认暗色，现随本次重设计废止；原文没有禁止模仿原生控件。旧视觉仅作为反参照。

## 3. 目标

- 布局分三个区域：**推进中**在左上，**待办**在左下，**已完成**在右侧纵贯整个工作区（约 20% 宽）。已完成栏和待办区可收起成细条（类 VS Code 侧栏），收起后推进中占满剩余空间；展开数与收起状态保存在本机 localStorage。
- 推进中的列由列 `id`/名称匹配（`doing`、`wip`、`正在`、`进行` 等）；匹配不到时取第二个活动列，只有一个活动列时该列既是待办也是推进中。其余活动列并排显示在待办区；`type: done` 列归入已完成。
- 推进中默认展开 1 项，可设为 1–5 项；展开的卡片正文、说明、进度和物证完整可见，其余任务以队列列出并可「提到最前」（`move_task` + `column_start`）。
- 卡片显示正文、截止日期、优先级、标签、部分完成比例、失败日期、说明和短 ID。
- 部分完成与失败在卡片内记录：展开进度条与一行说明，回车写入，`Esc` 取消，不打开对话框。
- 普通模式下勾选完成先经过一步确认（回车完成、`Esc` 取消）；该确认可在「设置」中关闭，偏好存本机。严格模式下的完成仍走结局确认对话框以决定 Git 物证，不受该设置影响。
- 左下角「设置」入口汇总本机偏好：完成确认开关与模型提供方配置。
- 已勾选完成但仍在活动列的任务显示在已完成栏，并标注所在列；可拖回待办或推进中恢复为未完成。
- 每次跨列移动都把任务放在目标列顶部，并使勾选状态与目标列一致：移入 `type: done` 列改为 `[x]`，移入活动列改为 `[ ]`。状态、列、说明与物证在一次 Rust 写入中完成。
- 移动父任务会移动整个子树。父任务跨越完成边界时，后代同步完成或恢复；进入完成列会清除后代的 `◐`/`⚠`，但保留其带锚点的说明。严格策略的结局说明描述本次父任务操作，不要求为每个后代重复填写。
- 普通任务拖入完成列或通过右键菜单完成时不弹安全确认框。严格模式以及带 `◐`/`⚠` 的任务仍打开结局对话框；确认完成后原子清理进度或失败 token，并放到完成列顶部。
- 拖放只发送 intent；Rust 成功回写并返回新 Snapshot 后，界面才确认最终位置。写入失败或取消结局填写时，卡片保持原位。
- 写入冲突时恢复到最新 Snapshot，并提示「文件已在外部更新，请重试」，不得保留虚假的乐观状态。
- 卡片支持应用内右键菜单和触屏可见的菜单按钮。菜单按任务状态提供快捷动作，「移动到…」子菜单列出项目的全部实际列；`Shift+F10` / Menu 键、方向键、Enter 和 `Esc` 可完成全部操作。

## 4. 截止日期筛选

- **逾期**：截止日期早于本地今天且未完成。
- **今天**：截止日期等于本地今天且未完成。
- **7 天内**：截止日期晚于今天的未完成任务，最多未来 7 天。
- 同一 Project Task 只归入一个区段，优先逾期、其次今天。筛选只作用于待办区，推进中始终完整显示。
- 计数为 0 的筛选禁用；筛选后没有任务时显示明确空状态，不显示虚假的统计数据。

## 5. 随记与分拣

- Capture 属于个人全局收件箱，不属于当前项目，也没有完成状态。
- 速记窗口由 `Cmd+Shift+Space`（macOS）或 `Ctrl+Shift+Space`（其他平台）唤起。
- 速记窗口预创建并隐藏；快捷键只执行显示和聚焦。目标唤起感知时间小于 100 ms。
- 输入区启动时为空。`Cmd/Ctrl+Enter` 保存，`Esc` 关闭；失焦时仅在文本非空且内容已变化时保存一次。
- 保存成功后立即清空并隐藏；失败时保留原文并显示可恢复错误。
- 分拣操作把 Capture 转化为当前项目指定列的 Project Task。若项目任务已创建但 Capture 删除失败，界面必须显示部分成功状态，避免用户重复创建。

### 5.1 AI 视图

数据来源与边界：

- 记录来自外部 agent 宿主（首个是 DeepSeek Harness），经 `todo ai upsert` 写入全局存储 `~/.todo/ai/sessions.json`；字段、状态与排序以 `ai-feed-spec.md` 为准。环境变量 `TODO_AI_STORE` 可覆盖存储路径，桌面端与 `todo serve` 与 CLI 采用同一约定。
- 记录不是 Project Task，不写入 `TODO.md`、Git 或 `.todo/history/`。`state` 由宿主拥有，桌面端不改写。
- 通道单向：宿主 → ToDo。桌面端只写三个本地标记：`acked_at`（标记已读）、`hidden`（移除）、`task_id`（转为任务）。这些标记不回传宿主；宿主发布更新的 `event_at` 时 `acked_at` 清空，`hidden` 与 `task_id` 保留。

布局：

- 侧栏「AI」入口右侧显示需要关注的数量：`waiting + failed + unread` 中尚未标记已读的记录，按当前范围计算，样式与「目标」旁的计数一致。
- 顶部状态胶囊：运行中 / 等你回复 / 完成未读 / 失败 / 已读 / 已处理，各带计数；点击切换显隐，`handled` 默认隐藏。范围切换「当前项目 / 所有工作区」：当前项目指 `workspace` 等于当前项目根或位于其下；未打开项目时只有所有工作区，切换不显示。
- 分区按契约顺序：等你回复 → 失败 → 完成未读 → 运行中 → 已读 → 已处理；同一分区内按 `event_at` 降序。已标记已读的 `waiting` / `failed` / `unread` 记录显示在「已读」，直到宿主发布新的活动。
- 卡片显示状态标记、标题（缺省「未命名会话」）、工作区目录名、提问（默认四行，可展开）、回答预览（默认三行，可展开）、改动文件（前 3 个与 `+N`）、相对时间，以及非 `completed` 的结局。改动文件以相对 `workspace` 的路径显示，宿主传入绝对路径时先去掉工作区前缀，不在工作区之下的只显示文件名并在悬停时给出完整路径。卡片网格按 `minmax(270px, 1fr)` 自动填充，1440px 宽的窗口一行四张，窄屏退到一列；卡片不得超出所在列。
- 动作：**打开会话**打开 `open_url`，只接受 `http` / `https`，缺省时禁用。打开方式由设置「打开会话」决定：「复用同一窗口」（默认）在 ToDo 自带的 `dsh-session` 窗口里打开，窗口已存在时只切换地址并置前，不新开标签页；「每次新开标签页」交给系统默认浏览器。该窗口不在任何 capability 的窗口列表中，远程页面拿不到 IPC；**转为任务**在当前项目新建 Project Task，正文取标题、缺省取提问，`↳` 说明写入「来自 `<source>` 会话 `<session_id>`：`<open_url>`」，随后回写 `task_id`，未打开项目或只读时禁用；**标记已读**；**移除**只影响本机列表。
- 空状态区分三种：尚未有宿主接入（存储文件不存在，提示 `todo hooks instructions --agent deepseek-harness` 与 `ai-feed-spec.md`）、宿主已接入但当前范围没有会话、全部被筛选掉。

数据通道：

- Tauri：命令 `ai_list` / `ai_ack` / `ai_remove` / `ai_link` / `ai_to_task` / `open_external` / `open_session_window`。桌面端监听存储目录，CLI 写入后发出 `desktop://ai-changed`，视图随之重读；目录不存在时先创建再监听。
- `todo serve`：`GET /api/v1/ai/sessions?workspace=<路径>&all=1` 与 `POST /api/v1/ai/sessions/{source}/{id}/ack|remove|link|to-task`；`--read-only` 下写入端点返回 403。Web 端每 5 秒轮询。
- mock：固定夹具覆盖全部状态与两个工作区，`?ai=none` 模拟未接入，`?ai=empty` 模拟已接入但为空。

## 6. 同步与错误

- 外部编辑 `TODO.md` 后，界面在 debounce 后加载新 Snapshot。
- Snapshot 带单调 revision 或内容 hash；界面丢弃迟到事件。
- 文件解析失败、存在 Git 冲突标记或锁超时，界面进入明确的只读或重试状态，不覆盖文件。
- 对账 Finding 只显示报告；桌面端不得绕过 spec §6.5 自动修改证据或完成状态。

## 7. 性能预算

- 冷启动到主窗口可交互：小于 2 秒。
- 已预创建的速记窗口唤起感知：小于 100 ms。
- 1,000 个 Project Task 的 Snapshot 构建：小于 100 ms。
- 常规 mutation 完成并返回新 Snapshot：目标小于 100 ms。
- 文件 watcher 从变更到界面事件：目标小于 300 ms。

性能数字必须通过真机测量记录，不用动画掩盖等待。

## 8. 首版不做

- 多仓聚合、周/月/年回顾、泳道和依赖图。
- 随记无限画布、富文本和自动 AI 分拣。
- 账号、登录、云同步和团队空间。
- 在 Tauri 移动端复用桌面文件访问模型。
