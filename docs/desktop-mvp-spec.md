# 桌面端 MVP 规格

本文定义 Tauri 桌面端的首版范围与验收标准。Project Task 继续以项目 `TODO.md` 为唯一事实源；桌面端只提供视图和安全编辑入口。

## 1. 信息架构

主窗口包含三个一级视图：

1. **看板**：按 `TODO.md` 的列展示 Project Task，支持新增、完成、取消完成和跨列拖动。
2. **今日**：派生展示逾期、今天到期和近期任务，不创建独立任务副本。
3. **随记**：展示个人 Capture 收件箱，并支持分拣为当前项目的 Project Task。

左侧导航显示当前项目、三个一级视图和同步状态。顶部命令栏提供项目切换、快速新增和对账入口。项目未打开时显示项目选择空状态，不自动接管或改写文件。

## 2. 视觉方向

界面采用「工程笔记与编辑台」风格，不使用通用 SaaS 后台模板。

- 背景：暖纸色 `#F3F0E8`，叠加低对比度网格或纸张纹理。
- 正文：墨蓝黑 `#1C2733`。
- 主强调：钴蓝 `#275EFE`。
- 警示与逾期：朱红 `#E6553A`。
- 完成与健康状态：苔绿 `#648C72`。
- 标题与界面文字：Bricolage Grotesque Variable。
- ID、日期、Git 物证和快捷键：JetBrains Mono Variable。
- 卡片使用清晰边框、轻微错位阴影和不完全对称的细节，避免大面积圆角胶囊。
- 不使用紫色主视觉，不默认暗色模式，不使用 Inter、Roboto、Arial 或系统字体。

动效只用于表达状态变化：首次加载分段显现、卡片跨列移动、速记窗口出现。禁止无意义的持续浮动和全局弹跳。

## 3. 看板

- 列宽在桌面窗口中保持稳定，列区域横向滚动。
- 卡片首屏显示正文、截止日期、优先级、标签、依赖状态和短 ID。
- 拖放只发送 intent；Rust 成功回写并返回新 Snapshot 后，界面才确认最终位置。
- 写入冲突时恢复到最新 Snapshot，并提示「文件已在外部更新，请重试」，不得保留虚假的乐观状态。
- 移入 `type: done` 列时沿用 core 的「状态只升不降」规则；移出完成列不自动取消完成。
- 列与卡片必须支持键盘聚焦。除拖放外，提供「移动到列」菜单。

## 4. 今日

- **逾期**：截止日期早于本地今天且未完成。
- **今天**：截止日期等于本地今天且未完成。
- **近期**：截止日期晚于今天的未完成任务；首版最多显示未来 7 天。
- 同一 Project Task 只出现一次，优先归入逾期或今天。
- 没有匹配任务时显示明确空状态，不显示虚假的统计数据。

## 5. 随记与分拣

- Capture 属于个人全局收件箱，不属于当前项目，也没有完成状态。
- 速记窗口由 `Cmd+Shift+Space`（macOS）或 `Ctrl+Shift+Space`（其他平台）唤起。
- 速记窗口预创建并隐藏；快捷键只执行显示和聚焦。目标唤起感知时间小于 100 ms。
- 输入区启动时为空。`Cmd/Ctrl+Enter` 保存，`Esc` 关闭；失焦时仅在文本非空且内容已变化时保存一次。
- 保存成功后立即清空并隐藏；失败时保留原文并显示可恢复错误。
- 分拣操作把 Capture 转化为当前项目指定列的 Project Task。若项目任务已创建但 Capture 删除失败，界面必须显示部分成功状态，避免用户重复创建。

## 6. 同步与错误

- 外部编辑 `TODO.md` 后，界面在 debounce 后加载新 Snapshot。
- Snapshot 带单调 revision 或内容 hash；界面丢弃迟到事件。
- 文件解析失败、存在 Git 冲突标记或锁超时，界面进入明确的只读或重试状态，不覆盖文件。
- 对账 Finding 只显示报告；桌面端不得绕过 spec §6.5 自动修改证据或完成状态。

## 7. 性能预算

- 冷启动到主窗口可交互：小于 2 秒。
- 已预创建的速记窗口唤起感知：小于 100 ms。
- 1,000 个 Project Task 的 Snapshot 构建：小于 100 ms。
- 常规 mutation 完成并返回新 Snapshot：目标小于 100 ms。
- 文件 watcher 从变更到界面事件：目标小于 300 ms。

性能数字必须通过真机测量记录，不用动画掩盖等待。

## 8. 首版不做

- 多仓聚合、周/月/年回顾、泳道和依赖图。
- 随记无限画布、富文本和自动 AI 分拣。
- 账号、登录、云同步和团队空间。
- 在 Tauri 移动端复用桌面文件访问模型。
