- **外网入口** `https://todo-sync.apikv.com`（Pangolin → cilium-gateway → todo ns）
- k1 集群 `todo` namespace；PVC `todo-sync-data`（openebs-lvm 5Gi，绑 k3 节点）
- 镜像 `ccr.ccs.tencentyun.com/sumery/todo-sync-api`，**由 ArgoCD Application `todo-sync-prod`

  `apps/sync-server/deploy/chart/todo-sync/values-prod.yaml` 的 `api.image.tag` 并推 GitLab main，
  **不要再用 `make sync-k8s-deploy`**（helm 与 Argo 会互相覆盖）
  （digest 钉版在 k3 上不可靠，见 §5）
- Token：k8s Secret `todo-sync-token`（key `VIRGO_SYNC_TOKEN`，64 位随机 hex，
  2026-11-11 由 `make sync-secret` 生成，明文无人记录）
- 拉取凭据：ExternalSecret `virgo-tcr`（ESO + openbao，**勿手工复制 Secret**——
  ownerRef 指向不存在的 ExternalSecret 会被 GC 回收，这是踩过的坑）
- API：`POST /links`（收藏优先，stub 即回 + 后台解析 + SSE ping）、`GET /articles`
  （全量对账）、detail/context/progress/read/delete/refetch、`GET /stream`（SSE）、
  `/healthz`（免鉴权）、静态网页端 + `/images`
- 网页端由同服务托管（`VIRGO_SYNC_WEB_DIR=/app/web`，打在镜像里）：
  **https://todo-sync.apikv.com** 即用，token 首次输入存 localStorage

### 同步模型（v2，全量对账 + 复用服务器正文）

URL 为唯一键；上行=本地有/服务器无 → `POST /links`（stub+context，服务器后台解析）；
下行=反向，或本地空壳而服务器已有正文 → 直接取服务器 `content_html` 与图片落库
（`ReadingStore::save_pulled`），**本地不再 refetch 原站**；已有条目**互不覆盖**
（备注随创建走）。解析只发生在本机新添加的链接上，失败按 1min/5min 退避、3 次终态。
同步带进度、取消与进程内单实例闸门。SSE 仅做刷新触发。详见
`docs/handoff-2026-11-11-sync-v2.md`；个人库 >5k 条时需 cursor 增量（spec §3）。

## 5. 踩过的坑（勿重踩）

1. **Cilium 网关 503**：k8s NetworkPolicy 的 `namespaceSelector io.cilium/k8s=default`
   匹配不到任何 namespace（sponsor 图的未验证模式）。正确写法 =
   `CiliumNetworkPolicy` + `fromEntities: [ingress, host, remote-node]`（virgo 图模式）。
2. **TCR digest 拉取在 k3 不可靠**：OCI index digest 与平台 manifest digest 都出现过
   NotFound（tag 始终可用）→ 当前按 tag 钉版；CI 化时重验。
3. **ESO 管理的 Secret 不能手工复制**：ownerRef 带走后 GC 回收；要在新 ns 用 ExternalSecret。
4. **Android 无 `~/.todo`**：`dirs::home_dir()` 为 None。capture store 用
   `$HOME`/TMPDIR 降级；reading store 已回退到应用私有 `files/.todo/reading`
   （2026-11-11），因此不选项目/目录也能保存链接；workspace 在移动端为空属预期。
   另外 Android 缺 rustls-platform-verifier 的 Kotlin 组件，HTTPS 统一走
   `todo_core::http_client_builder()`（移动端用随包 webpki 根证书），新加客户端别再直接
   用 `reqwest::blocking::Client::builder()`。
5. **openebs-lvm RWO 残留挂载**：pod 卡 FailedMount 时删 pod 等周期清理即可恢复。
6. Gradle 国内网络：gen/android 四个 gradle 文件已全部换阿里云镜像（勿重跑 init 覆盖）。
7. Node 26 无 corepack：Dockerfile 用 `npm i -g pnpm@12.15.0`。
8. `AGENTS.md` 的 `todo contract check`：全局安装的 todo CLI 没有 contract 子命令，
   用 `cargo run -p todo-cli -- contract check --root .`（verify-quick 已内置）。
9. **`adb shell input text` 遇中文输入法会把 hex 打成中文字符**（vivo 默认 IME）：
   验收填 token 改用 `adb push` + `run-as com.sumery.virgo cp` 写
   `shared_prefs/virgo-sync.xml`；另注意 `am start` 的 `-n` 要放在 `--es` 之前，
   否则会落到系统分享面板。
