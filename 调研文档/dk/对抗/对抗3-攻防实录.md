- **gpt-3 最强论据**:secret 前提非臆测——README 75 行自己承认配置内容「可能包含 API 密钥」;install/uninstall 是状态变更命令,被 provisioning/CI/求助日志捕获属正常使用形态;半警告主动制造「另两命令可贴」的差别暗示,提高外贴概率;一旦触发即凭据外泄,为 16 条中影响上限最高。
- **claude-3 最强论据**:伤害链需两个部分概率条件同时成立(settings.json 确有 secrets 为文档化但非普遍形态;stdout 被采集外发——CI 环境通常无真实密钥的 `~/.claude/settings.json`,本地终端显示自己的密钥不是泄露),期望伤害显著低于确定性触发的 C2/C5/C16;按全表统一的期望伤害加权标尺(C3 同理由持中)应判中,改判会破坏标尺一致性。
- 分歧本质:最坏影响加权 vs 期望伤害加权。留档,不影响修法。
