# Sumery Virgo · Project Contract Agent 实施规范

打开 `index.html` 查看完整的中文实施文档。

## 内容
- Project Contract 与文档角色映射
- 现有项目接管流程
- Skill 与 Agent 指令文件
- Git Hooks、CLI 与 CI 门禁
- 文档健康检查
- 环境快照
- 虚拟 Workspace 与项目详情 UI
- 分阶段计划、验收清单与 Agent 执行提示

## 素材
`assets/` 包含本地 SVG 架构图、接管流程图、Agent 门禁图和项目详情页示意图。

## 离线使用
HTML 不依赖外部 CDN。请保留 `assets/` 目录与 `index.html` 的相对路径关系。
